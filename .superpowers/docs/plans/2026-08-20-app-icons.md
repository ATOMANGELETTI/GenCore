# Nord App Icons, Tray Icons, and Tray Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the shared Tauri placeholder with Nord suite app icons, add glyph-only tray icons, and ship a Nord ui-kit right-click tray menu. Close hides to the tray; Quit exits.

**Architecture:** SVG masters (`icon.svg` tile + glyph, `tray.svg` glyph only) rasterize to Windows PNG/ICO and `tray.png`. A hidden `tray-menu` webview renders ui-kit `TrayMenu`. Rust `TrayIconBuilder` (no native menu) handles clicks. `gencore-core::tray_action` shows, hides, or quits. Main capability stays `["main"]`; tray-menu has its own capability file.

**Tech Stack:** SVG, `@tauri-apps/cli` 2.11.4 `tauri icon`, Tauri 2 `tray-icon` + `image-png`, React 19.2, ui-kit menu CVA, Vitest, node:test, cargo test.

**Spec:** `.superpowers/docs/specs/2026-08-20-app-icons-design.md`

## Global Constraints

- Latest **stable** only. No beta/rc/canary.
- Official Nord hex only: `#2E3440` and `#88C0D0` on icons. ui-kit uses existing semantic tokens, no ad-hoc hex.
- Flat: no drop shadows or gradients on icons or the tray menu.
- `{module}.{role}.{ext}`. Tests only under `tests/` (apps, ui-kit, crates, `scripts/tests`).
- UI talks to Rust only through `src/modules/ipc/`. Never `window.__TAURI__`.

- Windows x64 portable ZIP only. `bundle.active` stays `false`. `bundle.icon` stays PNG + `icon.ico` — **do not** add `icon.icns`.
- PNG/ICO are Git LFS; SVG is git text.
- Stage **only** the files listed in the task. Never `git add -A`.
