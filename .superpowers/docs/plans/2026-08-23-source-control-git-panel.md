# Source Control & Git Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a comprehensive, professional VSCode/Cursor-style Source Control panel in GenCore Terminal with a top icon subview menu on the Files tab, a pure-Rust `gitoxide` backend, dedicated Micro diff/editor terminal tabs, interactive visual Git Graph, and AI Assistant Git tools.

**Architecture:** 
- Backend: `crates/gencore-plugin-git` using `gix` (gitoxide) for fast, memory-safe Git repository operations and `rfd` for native Windows folder dialogs.
- Editor / Diff: Standalone portable `micro.exe` under `resources/micro/` launched in dedicated terminal tabs (`kind: "editor"`).
- Frontend: Split the Files tab into `FilesToolbar` with `tree` and `git` subviews; `SourceControl` handles No-Folder, Uninitialized, Clean, and Active-Changes states with collapsible staging accordions and an interactive SVG/canvas `GitGraph`.
- AI Assistant: Propose-and-confirm Git tools (`git_stage`, `git_commit`, `git_create_branch`, `git_stash`), live Git status in conversation snapshots, and AI commit message generation.

**Tech Stack:** React 19, TypeScript, Rust (2024 edition), Tauri 2, `gix` (gitoxide), `micro` editor, Lucide React, Radix UI primitives, Tailwind CSS v4, Vitest, Testing Library.

**Spec:** `.superpowers/docs/specs/2026-08-23-source-control-git-panel-design.md`

## Global Constraints

- Nord color palette hex tokens only.
- Strict modular naming: `{module}.{role}.{ext}` (JS/TS) or `{module}_api.rs` / `{module}_error.rs` (Rust).
- Object-form CSP, Isolation IPC allowlist with parameter validation; `withGlobalTauri: false`; never `window.__TAURI__`.
- Capabilities: scoped least-privilege grants in `main.json`; no `core:default`.
- Plugin ID must equal `CARGO_PKG_NAME` (`gencore-git` for crate `gencore-plugin-git`).
- Windows x64 portable distribution; stable dependency versions only.
