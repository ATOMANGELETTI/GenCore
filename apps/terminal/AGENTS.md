# Terminal app

Template Tauri 2 shell with a real PTY backend. The Files tab is a real drive-rooted tree.

- Package `@gencore/terminal`, identifier `com.gencore.terminal`, Vite port **5173**
- `AppShell` density `compact`. Center copy must be exactly `Tauri Terminal Template` plus the version from `get_app_info`
- Window chrome goes through `src/modules/ipc/ipc.window.ts` (`getCurrentWindow()`). App info through `ipc.app-info.ts`. PTY through `ipc.pty.ts`. Pinned tabs through `ipc.pinned.ts`. Gemini Assistant through `ipc.assistant.ts`. UI never calls `invoke` directly
- Files tab uses `gencore-fs` `list` / `list_drives` / `create_file` / `create_dir` / `watch` / `unwatch` through `src/modules/ipc/ipc.fs.ts`
- Files tab right-click uses the ui-kit ContextMenu (Terminal-owned items: Expand/Collapse, New File, New Folder, Refresh, Copy Path; blank area Refresh + Collapse All). `C:\` expands on load. No new Isolation grants
- Isolation hook allowlist and `capabilities/main.json` stay least-privilege: window close/minimize/toggle-maximize/start-dragging/theme + `gencore-core:allow-get-app-info` + scoped `opener:allow-open-url` for `https://github.com/ATOMANGELETTI/GenCore`
- Isolation also allowlists the six `gencore-fs` commands above, the four `gencore-pty` commands (`open` / `write` / `resize` / `close`), `plugin:gencore-core|get_system_telemetry` (empty args), `plugin:gencore-core|load_pinned_tabs` (empty args) and `save_pinned_tabs` (`{ json }`), the twelve `gencore-assistant` commands (`list_conversations` / `create_conversation` / `delete_conversation` / `list_messages` / `send_message` / `cancel_turn` / `confirm_action` / `reject_action` / `get_agent_settings` / `set_agent_settings` / `set_api_key` / `clear_api_key`), **and** `plugin:event|listen` / `plugin:event|unlisten` reconstructed only for `gencore-fs://entry-changed` (Any), `gencore-pty://data` (Any), `gencore-pty://exit` (Any), `gencore-assistant://token` (Any), `gencore-assistant://turn` (Any), `gencore-assistant://error` (Any), `gencore-assistant://ui-action` (Any), and `tauri://theme-changed` (`{ kind: "Window", label: "main" }`)
- Capabilities grant the matching `gencore-fs:allow-*`, `gencore-pty:allow-open` / `allow-write` / `allow-resize` / `allow-close`, `gencore-core:allow-get-system-telemetry`, `gencore-core:allow-load-pinned-tabs` / `allow-save-pinned-tabs`, the twelve matching `gencore-assistant:allow-*` commands, plus `core:window:allow-theme` and `core:event:allow-listen` / `allow-unlisten`
- Config tab (left panel) lists Appearance: Match system, Polar Night, Snow Storm. Preference is `{ version: 1, theme }` in `localStorage` key `gencore.terminal.config`. `system` maps OS dark/null/failure → Polar Night, light → Snow Storm via `getWindowTheme` / `subscribeWindowTheme`. Explicit Polar Night or Snow Storm ignores the OS. Config also has Assistant (Gemini API key row + four model radios, default `gemini-3.7-flash`) and Context (Terminal context lines, 20–200, default 80) sections after Appearance, backed by `gencore-assistant`'s own settings, not `gencore.terminal.config`
- Assistant's portable SQLite database (`gencore-assistant.sqlite`) lives under `GENCORE_DATA_DIR` or `{exe_parent}/data/`; `scripts/tauri-dev-terminal.mjs` (the `tauri:dev` script) sets `GENCORE_DATA_DIR` to the repo's `.data/terminal/`
- Still no `stat`, `gencore-pty:default`, Explorer PTY, `core:default`, `opener:default`, `core:event:default`, `core:window:default`, `core:window:allow-set-theme`, emit, or agent file create/read tools (Assistant only has `pty_write` / `switch_tab` / `reveal_in_files`; file tools wait for Explorer)
- Repo URL opens through `ipc.opener.ts` (`openRepoInBrowser`)
- `gencore-fs`, `gencore-pty`, and `gencore-assistant` are registered in Rust (`gencore-assistant` registers after `gencore-pty` so its commands can read the PTY plugin's managed session state). Grant only the six Files-tab `gencore-fs` commands, the four Terminal PTY commands, and the twelve `gencore-assistant` commands the UI wrappers invoke
- Override density only in `src/modules/app/app.theme.css`. Keep Nord tokens
- Tests: `apps/terminal/tests/` (JS) and `apps/terminal/src-tauri/tests/` (Rust)
- Release packaging is root `pnpm package:win64` (Windows x64 portable ZIP only)
